# 产品板硬件事实

本页只保留影响当前 Product Modbus 固件的已核对事实。详细设计附件不放在本交付分支工作树中，需要追溯时查看 Git 历史或硬件设计库。

## 支持的板卡

| 项目 | F1_TEST v1.5 实验板 | F1_POWER_V004 |
|---|---|---|
| MCU | STM32G431RBT6 | STM32G431RBT6 |
| 产品构建目标 | `product-modbus` | `power-product-modbus` |
| RS485 | CN4 | CN3 |
| USART2 | PA2 TX、PA3 RX | PA2 TX、PA3 RX |
| RS485 DE/RE | PA4，高发送、低接收 | PA4，高发送、低接收 |
| RS485 收发器 | U17 `SN65HVD3082EDR`，非隔离，参考 `DGND` | U28 `SM4500(H)`，逻辑侧与总线侧隔离 |
| 接口引脚 | CN4：3.3 V、A、B、DGND | CN3：隔离侧 3.3 V、P、N、GND |
| 终端/偏置 | R37=120 Ω，并有 100 kΩ偏置 | R90/R91 标为 NC，未确认板载终端/偏置 |
| VBUS ADC | PA6 / ADC2_IN3 | PC2 / ADC2_IN8 |
| 加热 | 需按实验板装配确认 | PB13/`HEAT` 一路已确认 |

两个固件的 VBUS ADC 路由不同，不得混刷。

F1_TEST 的 RS485 收发器与 MCU、功率控制共用 `DGND`，外接主站时必须控制 A/B 的共模
电压；2026-09-29 实测仅接 A/B 时，PWM 开启后通信大量超时，补接 CN4 `DGND` 后恢复。
POWER V004 的隔离器会阻断功率侧地扰动直接进入 485 总线侧，所以同一套主站和短线在
仅接 P/N 时也可能稳定工作。这是隔离结构带来的差异，不表示 POWER CN3 的总线侧 `GND`
没有用途；长线、不同主站或更强共模环境仍应按系统接地和隔离方案连接。

## 电机功率级

- TIM1 产生三相互补 PWM，PWM 频率 16 kHz。
- PA8/PA9/PA10 为三路高桥 PWM，PA7/PB0/PB1 为三路低桥 PWM。
- PA11 接 TIM1 BKIN2 硬件保护输入。
- ADC1/ADC2 与 TIM1 同步进行三相电流采样。
- POWER V004 使用 SDM15G60FB 三相功率模块。
- 电机接口为 U/V/W；继电器控制位于 PB11/`CONTROL_L`。

当前 M1 模型：4 对极、相电阻 2.25 Ω、Lq 5.55 mH、反电势 8.9286 Vrms 线线/kRPM。更换电机时必须重新核对模型和限流参数。

## 加热与零点

- POWER V004 的 PB13 连接 `HEAT`，经 S8050 和 MOC3021S 驱动 BTA24-600B 双向可控硅。
- PB12/`ZERO` 是双边沿零点中断输入。
- 固件在零点中断中按 0..13 档装载 TIM2 相位定时，并由 PB13 输出控制。
- PB14 是旧软件中的 `HeatRoll` 名称，但 POWER V004 原理图和 PCB 没有第二路连接。本目标强制该通道为 0。
- Modbus 加热状态是命令状态，不是电流、温度或实际功率反馈。

## 通信接口

- USART2/RS485 是产品控制接口：1,000,000 baud、8N1、Modbus RTU、从站 3。
- USART1 PB6/PB7 保持 115200 baud，仍属于 MCSDK Monitor，不是 ASCII 产品控制口。
- USART3 PC10/PC11 保持 115200 baud，但没有确认可用的外部产品接口。
- 产品 STOP 会在实时条件恢复后自动确认欠压、启动失败和速度反馈故障；FOC 超时、过压、过温、BKIN/硬件过流和软件内部错误仍保持锁存。
- 产品上电阶段会自动确认一次满足严格安全条件的 BKIN 启动瞬态；初始化完成后的 BKIN 事件不会自动确认。

## 保护边界

- 总线欠压、过压和 TIM1 Break 故障由 MCSDK 状态机处理。
- `OCCURRED=0x0040` 对应历史 Break 事件；当前故障消失后仍可能需要 `ACK` 才能从 `FAULT_OVER` 返回 IDLE。
- 当前温度传感器配置是虚拟传感器，不能声称具有真实硬件过温保护。
- ST-LINK 供电只能支持 MCU 和低压通信调试，不能据此判断母线、电机、继电器或加热功率级工作。

## 固件修改检查项

修改引脚、ADC、PWM、保护、加热或串口后，至少检查：

1. 构建目标与实际板卡一致；
2. VBUS ADC 通道正确；
3. TIM1 Break 极性和过滤未改变；
4. PB13 上电和停止状态保持关断；
5. USART2 波特率与主站一致；
6. FC03/FC04 回读、实际转速和实际加热功率均经过验证。
